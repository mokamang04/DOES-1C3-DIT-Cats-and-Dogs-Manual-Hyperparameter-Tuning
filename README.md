# Manual Hyperparameter Tuning and Performance Evaluation of a Convolutional Neural Network for Binary Image Classification of Cats and Dogs

## Activity Overview

This repository contains the implementation, experimental results, and documentation for the **Manual Hyperparameter Tuning and Performance Evaluation of a Convolutional Neural Network (CNN) for Binary Image Classification of Cats and Dogs**.

The activity investigates how changes in selected CNN hyperparameters affect model training, validation, and classification performance. Different configurations are manually tested, trained, evaluated, and compared based on their resulting performance metrics.
